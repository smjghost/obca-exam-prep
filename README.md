# OBCA 备考刷题系统 (OBCA Exam Prep System)

欢迎使用 **OBCA 备考刷题系统**！这是一款专为 OceanBase 数据库认证专员（OBCA）考试量身定制的单页刷题应用。本系统无需连接复杂的后端，所有做题记录与错题本均自动保存在您的本地浏览器中（Local Storage），为您提供纯净、快速、不被打扰的备考体验。

## 🌟 核心功能特性

### 1. 自由练习模式 (Practice Mode)
该模式适合日常不限时的刷题与知识点巩固。
- **分类题库**：系统内置了**单选题**、**多选题**和**判断题**的专项题库。您可以通过顶部的按钮随时切换。
- **背诵与自测双模式**：
  - 做题时，可随时点击左下角的**“翻转看答案”**（快捷键：空格键）查看正确答案与官方深度解析。
- **错题智能收录**：
  - 看完解析后，如果您觉得这题没掌握，可以点击**“答错了 (收录错题)”**，该题会自动进入您的错题本。
  - 如果已经完全掌握，点击**“已掌握 (下一题)”**，系统会自动将该题从错题本中移除（如果您之前做错过的话），并无缝切换至下一题。
- **乱序与题号跳转**：支持开启“乱序”打乱题库顺序；也可以点击“题号列表”打开答题卡，直接跳转到指定的题目。

### 2. 模拟考试模式 (Exam Mode)
该模式完全模拟真实的 OBCA 考试环境，帮助您进行考前冲刺。
- **标准试卷结构**：每次模考会自动从题库中随机抽取 50 道题（包含单选、多选、判断），满分 100 分，及格分 60 分。
- **倒计时限制**：考试限时 60 分钟。您可以随时查看右上角的剩余时间。
- **遇阻标记**：遇到不确定的题目，可以点击下方的**“标记 (★)”**。在“答题卡”网格中，被标记的题目会带有小星星，方便您在交卷前重点检查。
- **自动评分与错题收录**：
  - 交卷后系统会立即进行评分，并自动给出及格/不及格的反馈。
  - 在考试中**做错的题目，会自动被加入到您的“错题本”中**。
  - 在考试中**做对的题目，会自动从您的“错题本”中洗白并移除**。

### 3. 错题本与复盘 (Wrong Cards & Review)
- **错题本集中攻克**：在“自由练习”模式下，点击红色的“错题本”按钮，即可专门针对您曾经做错的题目进行练习。
- **清空错题本**：当您将所有错题都掌握后，可以点击顶部的“清空”按钮一键清空错题记录。
- **模考复盘**：在“模拟考试”的首页（成绩记录看板），您可以点击历次考试的“查看复盘”按钮。复盘模式下不仅会显示每道题的标准答案、您的作答情况以及得分，还会**高亮您当时“遇阻标记”的题目**，极大提升查漏补缺的效率。
- **导出纯净题库**：您也可以随时将错题本导出为 `.csv` 文件，方便打印或分享。

## ⌨️ 快捷键指南

为了让您能够以最快的速度刷题（特别是使用电脑备考时），系统在“自由练习”模式下提供了原生快捷键支持：

- `←` (左方向键)：返回上一题
- `→` (右方向键)：进入下一题
- `Space` (空格键)：翻转题目，查看答案与解析
- `1` (数字键 1)：标记为“答错了”（仅在翻转后可用）
- `2` (数字键 2)：标记为“已掌握”（仅在翻转后可用）

## 💾 数据持久化说明

本应用采用了纯前端 Local Storage 存储方案：
- 您的“错题本记录”、“历次模考成绩与答卷细节”均**加密保存在您当前使用的浏览器本地**。
- 请注意：如果您清理了浏览器的本地缓存（LocalStorage），或者更换了电脑/浏览器，之前的错题和模考记录将会丢失。如果需要备份，请善用错题本的“导出”功能。
